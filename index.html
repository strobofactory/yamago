よくある質問

記録の途中で軌跡が途切れてしまいます

位置情報の権限が「使用中のみ許可」になっていると、画面を消したときに GPS 記録が止まります。iOS の 設定 → yamago → 位置情報 で「常に」を選択してください。

登山中は画面を消していても、この設定によりバックグラウンドで軌跡の記録が続きます。位置情報が端末の外へ送信されることはありません。

Apple Watch に心拍数が表示されません

Watch 側の yamago が起動しているかご確認ください。iPhone で記録を開始すると Watch 版が自動起動しますが、起動しない場合は Watch で手動で yamago を開いてください。

また、iPhone の yamago 設定 → ヘルスケア連携 で連携がオンになっているか、iOS の設定 → ヘルスケア → データアクセスとデバイス → yamago で許可されているかもあわせてご確認ください。

ヘルスケア連携の画面で接続が終わりません

接続に15秒以上かかる場合は自動的に中断され、iOS 設定への案内が表示されます。iOS の 設定 → ヘルスケア → データアクセスとデバイス → yamago から直接許可することもできます。

電波の届かない山でも地図は見られますか？

はい。事前に地形図をダウンロードしておけば、圏外でも現在地と地図を表示できます（オフライン地図は PRO 機能です）。ダウンロードは電波のある場所・Wi-Fi 環境で済ませておくことをおすすめします。

PRO の解約・購入の復元はどこからできますか？

解約は iPhone の 設定 → 一番上の Apple Account → サブスクリプション から行えます。解約後も、支払い済みの期間の終わりまで PRO 機能を利用できます。

機種変更などで購入を復元する場合は、同じ Apple Account でサインインのうえ、アプリ内の PRO 画面から「購入を復元」を実行してください。

記録データの保存先と削除方法を教えてください

登山記録はお使いの端末と、ご本人の iCloud（プライベートデータベース）にのみ保存されます。開発者や第三者が内容にアクセスすることはありません。

アカウントと記録をすべて削除する場合は、アプリ内の 設定 → アカウントを削除 から実行できます。
